**Phantom** es una herramienta hecha en Python para codificar y decodificar imagenes a **Base64**.

La idea de este programa es ayudar con experimentos de ciberseguridad que necesiten transferir imágenes codificadas por distintos medios como un .txt desencriptable y liviano.

> 🚧 **Estado:** en desarrollo _pero activo_

---

## ⚡ Características

- 🔤 **ASCII**: codifica y decodifica imagenes de formato .png (`de momento`)
- 📄 **TXT**: Devuelve la codificación como un archivo .txt
